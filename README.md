# HR Analytics Dashboard | Employee Retention Analysis
## Project Overview
Analyzed employee data to identify attrition patterns and explore factors associated with employee retention.

## Objectives
- Analyze employee attrition across departments and job roles.
- Examine relationships between monthly income and attrition.
- Evaluate work-life balance and employee experience.
- Explore years since last promotion and employee attrition.

## Tools & Technologies
- Microsoft Excel
- MySQL
- Microsoft Power BI
- Tableau Public
- Data Cleaning and Analysis
- KPI Reporting and Data Visualization

## Key Analysis
- Employee Attrition Rate
- Monthly Income Analysis
- Department and Job Role Analysis
- Work-Life Balance
- Working Years and Years Since Last Promotion

## Key Learnings
Developed practical skills in analyzing HR data, identifying workforce trends, and presenting findings through interactive dashboard visualizations.
